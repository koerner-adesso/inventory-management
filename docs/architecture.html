Factory Inventory Management System

Architecture overview: Vue 3 SPA, FastAPI backend, in-memory JSON data. No database.

System architecture

Three tiers, two processes. The browser talks to the API directly over HTTP; CORS is open for local development.

Data flow

How a filter change on the dashboard becomes updated numbers on screen.

  1. User picks a filter
    FilterBar writes to shared refs in useFilters (period, location, category, status). The refs are module-level, so every view sees the same state.
  2. View reacts
    A watcher in the active view calls getCurrentFilters(), which maps the period to a month param.
  3. api.js builds the request
    Params equal to all are dropped. Views fetch in parallel, e.g. summary, orders, inventory, backlog on the dashboard.
  4. FastAPI filters in memory
    apply_filters matches warehouse, category, status. filter_by_month accepts 2025-09 or a quarter like Q3-2025.
  5. Response is validated
    Pydantic response_model checks shape. Summary and report endpoints return computed dicts.
  6. Client derives and renders
    Raw data sits in refs. Chart series and totals are computed properties.

GET /api/demand, /api/backlognone
GET /api/spending/*none
GET /api/reports/quarterly, /monthly-trendsnone, computed from all orders
GET /api/inventory/{id}, /api/orders/{id}404 if not found

Inventory has no time dimension, so the month filter never applies to it.

Gaps found while reading the code

Places where the frontend and backend do not line up today.

  • missing endpoints api.js calls /tasks (GET, POST, DELETE, PATCH) and /purchase-orders (POST, GET by backlog item). None exist in main.py, so those calls would return 404. The backend does define a CreatePurchaseOrderRequest model that no route uses.
  • missing component Dashboard.vue renders <PurchaseOrderModal>, but no such file exists in components/ and it is not imported.
  • unrouted view views/Backlog.vue is not registered in the router. Backlog data is only reached through the Dashboard.
  • inconsistency Reports.vue bypasses api.js and hardcodes the base URL, as does api.js itself. There is no environment-based config.
  • hardcoded year Quarter mapping is fixed to 2025.
  • demo scope No auth, open CORS (*), no persistence. The "current user" in useAuth.js is static mock data.
